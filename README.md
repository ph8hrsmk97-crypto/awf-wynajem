# Wynajem obiektów AWF Warszawa – projekt koncepcyjny

Prototyp strony wynajmu obiektów sportowych i sal Akademii Wychowania Fizycznego Józefa Piłsudskiego w Warszawie:
katalog obiektów z filtrami dyscyplin, kalkulator kosztów najmu (liczy terminy i godziny z dat), lista sal
seminaryjnych, formularz zapytania (bez rezerwacji online), wersja PL/EN.

Ceny według Zarządzenia Kanclerza AWF nr 8/2024/2025 w brzmieniu Zarządzenia nr 63/2025/2026 (od 1.08.2026).
Strona statyczna – wystarczy otworzyć `index.html` lub włączyć GitHub Pages (gałąź `main`, katalog główny).

- `data.js` – cennik i opisy obiektów
- `i18n.js` – teksty PL/EN
- `app.js` – logika
- `PROJEKT.md`, `NAZWY.md` – notatki projektowe i ujednolicenie nazw
